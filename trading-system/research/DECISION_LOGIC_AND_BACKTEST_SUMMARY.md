# EAの売買判断ロジックの言語化と、これまでのバックテスト検証結果

- 作成日: 2026-08-25
- 対象: `trading-system/mt4/USDJPY_LowRisk_Trend_EA.mq4`
- 対象ビルド: **CC002**（`claude/ea-v0.3.0-risk-management`, Phase 1-4 + Phase 5-1）
  - `main`側の`trading-system/mt4/`にあるコピーは**CC001**（Phase 1-4のみ、日次損失上限・連敗制限なし）
- 前提: `AllowLiveTrading=false`。**このEAは実口座で一度も発注していない。**
  以下の「売買する時の思考」は、バックテストとデモで実行されている判断ロジックそのものである。

## 第1部 売買判断の言語化

### 1-0. 大前提：判断は「確定した1本前のH1足」だけで行う

すべての指標は`shift=1`、つまり**直前に確定したH1足**の値で評価する。
形成途中の足（`shift=0`）は一切見ない。判断は1時間に1回、足が確定した瞬間だけ発生する。

これは「未来を覗かない」ための設計であり、`RESEARCH_CHARTER.md`のNo-lookahead要件に対応する。
言い換えると、EAは**足が閉じるまで何も決めない。閉じたら即座に決めて、次の1時間は何もしない。**

### 1-1. 発注前に「そもそも撃てるか」を確認する（4つの門番）

シグナルを見る前に、次の条件を順に確認する。1つでも引っかかればその足は見送る。

| # | 確認 | 落ちた場合の意味 |
|---|---|---|
| 1 | 既にポジションを持っていないか | **同時保有は最大1つ**。ナンピン・両建て・グリッドは構造的に不可能 |
| 2 | 実口座ではないか | `AllowLiveTrading=false`なら発注を物理的にブロック |
| 3 | スプレッドが3.0 pips以下か | 広がっている＝流動性が薄い、指標発表直後等。コストが読めない場面では撃たない |
| 4 | 日次損失上限・連敗上限に達していないか | 残高の-2.0%到達、または3連敗で**その日は新規を止める**（保有中のポジション管理は継続） |

ここまでが「環境チェック」。相場の向きは、この後で初めて見る。

### 1-2. 買いシグナルの思考（3段階）

#### 段階1：そもそも上昇トレンドか（`GetTrendDirection`）

以下の**3つすべて**が同時に成立していること。

```
終値[1]   >  EMA200[1]      … 長期の趨勢の上側にいる
EMA20[1]  >  EMA75[1]       … 短期が中期を上回っている
EMA75[1]  >  EMA200[1]      … 中期が長期を上回っている
```

言語化すると「**短期・中期・長期の平均線がきれいに上から順に並んでいて、価格がその全部より上にいる**」。
1つでも崩れていればトレンドなしと判定し、買いも売りもしない。

#### 段階2：そのトレンドに勢いがあるか（ADXフィルター）

```
ADX(14)[1] >= 20.0
```

「並び順は良いが誰も動かしていない」レンジを弾くための足切り。

#### 段階3：押し目をつけて戻ってきたか（`CheckPullbackSignal`）

ここがこのEAの本体である。「トレンド方向へそのまま飛び乗る」のではなく、
**一度20EMAまで下がってきて、そこから復帰した瞬間に乗る**。

1. **接触足を探す**: `shift=1`から`shift=5`へ遡り、**最初に見つかった**「高値と安値の範囲が
   20EMA±3 pipsの帯と重なっている足」を接触足とする
   - 見つからない → 不成立（押し目をつけていない＝既に走り去っている）
2. **深すぎないか確認**: その接触足の安値が20EMAより **10 pipsを超えて下**に潜っていたら不成立
   - **より古い接触足へのフォールバックはしない。** 「浅く触った古い足」を探しに戻ると
     都合の良い足を選べてしまうため、最新の接触足がダメなら全体を不成立にする
3. **復帰したか確認**: `終値[1] > EMA20[1]`
   - 押し目をつけただけでは撃たない。**20EMAの上へ終値で戻ったこと**を確認して初めて撃つ

3つ揃って、初めて「買い」になる。

#### 買いの思考を一文にすると

> 直前の確定足の時点で、20/75/200EMAが上向きに整列し価格がその上にあり、ADXが20以上で勢いがあり、
> 直近5本以内に20EMAへ浅く（10 pips以内）触れて押し目を作り、その終値が20EMAの上に戻っている。
> このとき初めて買う。

### 1-3. 売りシグナルの思考

**完全に鏡像**である。特別扱いは一切ない。

```
終値[1]   <  EMA200[1]
EMA20[1]  <  EMA75[1]
EMA75[1]  <  EMA200[1]
ADX(14)[1] >= 20.0
直近5本以内に20EMA±3pips帯へ接触、かつ高値の逸脱が10 pips以内
終値[1] < EMA20[1]（戻り売りの復帰確認）
```

判定順序は買いが先、売りが後だが、トレンド方向は排他的なので両方成立することはない。

### 1-4. いくら賭けるか（ロット決定の思考）

**「何ロット買うか」ではなく「いくら失う覚悟をするか」から逆算する。**

```
1. 損切り幅(pips) = ATR(14)[1] × 1.5
   → 下限 max(5 pips, ブローカーのStopLevel)、上限 100 pips でクリップ
2. 許容損失額 = 口座残高 × 0.5%
3. 必要ロット = 許容損失額 ÷ (損切り幅pips × 1pipあたりの損益)
4. ロットステップで【切り捨て】、上限1.0ロットとブローカー上限でクリップ
5. 最小ロット未満、または証拠金不足 → 【発注しない】
```

重要な点：
- **ボラティリティが大きい局面ほどロットが小さくなる。** 損切り幅がATRで広がり、
  同じ0.5%を守るためにロットが自動で削られる。「大きく動くから大きく張る」の逆をやる
- 丸めは**必ず切り捨て**。リスクが設定値を超える方向へは絶対に丸めない
- 撃てない条件では0を返して**見送る**。無理に最小ロットで撃つことはしない

### 1-5. どこで降りるか（決済の思考）

エントリーと同時にSL/TPを置き、**あとは触らない**。

```
損切り = エントリー ∓ (ATR(14)[1] × 1.5)
利確   = エントリー ± (損切り幅 × 2.0)      … リスクリワード 1:2 固定
```

現行ビルド（CC002）では、**建値移動もトレーリングも金曜決済も動いていない**。
`EnableBreakEven=true`という入力値は存在するが、CC002ではPhase 5-2未実装のため
入力値検証しかしていない。実装は`claude/ea-breakeven-exit-protection`ブランチのみで、
判定は`HOLD`（第2部参照）。

つまり決済の思考は現時点で「**置いたら動かさない。SLかTPのどちらかに当たるまで待つ**」である。

### 1-6. 全体像

```
H1足が確定
  ↓
① ポジション保有中？ → YES: 何もしない
  ↓ NO
② 実口座？ → YES: ブロック
  ↓ NO
③ スプレッド > 3.0 pips？ → YES: 見送り
  ↓ NO
④ 日次-2.0%到達 or 3連敗？ → YES: 本日は新規停止
  ↓ NO
⑤ EMA20/75/200の整列は？ → 上昇なら買い検討 / 下降なら売り検討 / それ以外は何もしない
  ↓
⑥ ADX >= 20？ → NO: 見送り
  ↓ YES
⑦ 直近5本で20EMAへ接触した？ → NO: 見送り
  ↓ YES
⑧ その接触は10 pips以内の浅さ？ → NO: 見送り（古い足は探さない）
  ↓ YES
⑨ 終値が20EMAの向こう側へ復帰した？ → NO: 見送り
  ↓ YES
⑩ ATR×1.5でSL、その2倍でTP、残高0.5%からロットを逆算
  ↓
⑪ ロットが最小未満 or 証拠金不足 → 見送り
  ↓
発注（以後、SL/TPに当たるまで放置）
```

## 第2部 過去ログでのバックテスト検証結果

### 2-1. ベースライン成績

| 実験 | ビルド | データ | 総取引 | PF | 勝率 | 純損益 | 最大DD |
|---|---|---|---|---:|---:|---:|---:|
| EXP-001 | CC001 | DS001 | 184 | **0.74** | 29.89% | -6,128.31 | 7.45% |
| EXP-002 | CC002 | DS004 | 196（明細195） | **0.76** | - | -6,184.64 | 7.45% |
| EXP-003 | CC002 | DS005 | 194 | **0.75** | 29.38% | マイナス | - |

（EXP-003は日次損失上限の機能試験用に非標準パラメータで実行したもので、収益性評価には使わない。
PFは参考記録。）

**3回とも一貫してPF < 1.0**。特定の1年・特定のビルドの問題ではない。
年別に割っても2025年PF 0.744 / 2026年PF 0.741 と、どちらの年も負けている。

### 2-2. 最大の発見：損失のほぼ全額が「売り」から出ている

EXP-001/EXP-002を方向別に分解した結果。

| データ | 買い | 売り |
|---|---|---|
| DS001 (EXP-001) | 134件, PF **1.02**, 勝率34.33%, +286.75 | 49件, PF **0.305**, 勝率16.33%, **-6,473.65** |
| DS004 (EXP-002) | 141件, PF **1.059**, 勝率34.04%, +923.73 | 54件, PF **0.313**, 勝率16.67%, **-7,108.37** |

**買いはほぼ損益分岐、売りが単独で全損失を作っている。**
売りの勝率16%台は、リスクリワード1:2（=損益分岐に必要な勝率は約33%）に対して半分しかない。

### 2-3. この非対称は「枠の奪い合い」ではなく信号品質の差（EXP-005）

「同時保有1ポジションなので、悪い売りが良い買いの機会を潰しているだけでは？」という
対立仮説を、`EnableLong`/`EnableShort`を片方ずつ切って検証した。

| | EXP-002の買いサブセット | Run A（買いのみ実行） |
|---|---|---|
| 取引数 | 141 | 142（+1件のみ） |
| 勝率 | 34.04% | 34.51% |
| PF | 1.059 | 1.06 |

**ほぼ完全に一致した。** 枠の競合は起きていない。売りが弱いのは**売り信号そのものの質**である。

### 2-4. 試した改善策と結果（4件すべてHOLD）

| 実験 | 仮説 | 変更点 | 結果 | 判定 |
|---|---|---|---|---|
| EXP-006 | H004: NYセッション(15-22時)を除外すれば改善 | 取引時間フィルター | 買いPF 1.059 → 1.047($) / 1.021(R)。**横ばい〜微減** | **HOLD** |
| EXP-007 | H005: +1.0R到達で建値へSL移動すれば改善 | 建値移動を実装 | 全体PF 0.76 → 0.78 (+0.02)。取引数195→239へ増加（経路依存） | **HOLD** |
| EXP-008 | H006: 50バー以上続いたトレンドへの遅い買いを除外 | 買いのみトレンド成熟度フィルター | 買いPF 1.059 → **1.248**、期待値R +0.0180 → 基準の4倍超 | in-sampleでADOPTED |
| EXP-009 | H006のOOS検証（別期間） | 同上 | 期待値R +0.1487 → +0.2083（基準の2倍達成）。だが**買い取引数42件 < Guardrail 50件** | **HOLD** |
| EXP-010 | H006の補助OOS（さらに別期間） | 同上 | 期待値R +0.0215 < 基準 +0.0286。**未達** | **HOLD** |

EXP-009は成績自体は良かったが、**事前登録したGuardrail（取引数50件以上）を満たさなかったため、
ルール通りADOPTEDに昇格させずHOLDにした**。結果を見てから基準を緩めることはしていない。

### 2-5. H006が採用に至らなかった理由の構造

「50バー」という固定閾値が、期間ごとにまったく違う強さのフィルターとして働いていた。

| 期間 | 買いシグナルの削減率 |
|---|---|
| DS004（発見期間） | -36.9% |
| DS013（OOS） | -53.8% |
| DS015（補助OOS） | -71.1% |

同じ「50バー」なのに、除外される割合が37%〜71%まで振れる。
これは50が絶対的な水準ではなく、**その期間のトレンド継続長分布に対する相対位置**で
効き方が決まっていることを意味する。

自然な対処として「相対化（パーセンタイル化）すれば安定するはず」という仮説を立て、
`O-007`で検証したが、**棄却された**（相対版の削減率のばらつき27〜29ポイント vs 固定版33.8ポイント。
改善したが安定と言えるほどではない）。

### 2-6. さらに深刻な構造的問題

無改造のEAそのもののPFが、期間によって大きく振れている。

| 期間 | 無改造EAの全体PF |
|---|---|
| DS004 | 0.76 |
| DS013 | 1.16 |
| DS015 | 1.17 |

**期間による変動（0.76〜1.17）が、これまで測定できた最良の改善効果（期待値R +0.02〜+0.06）を
桁違いに上回っている。** つまり、いま何かを改善しても、その効果が期間差のノイズに埋もれて
判別できない。

売りの挙動も期間ごとに別物である：DS004で売りPF 0.313（大赤字）、DS013で1.149（黒字）、
DS015で0.963（ほぼ損益分岐）。**「売りが弱い」という最大の発見すら、特定期間に固有だった
可能性がある。**

これが、ロジック探索をいったん停止して**Data Expansion / Validation Phase**（データを
2016〜2026へ拡張し、ウォークフォワードで評価する基盤づくり）へ移った理由である。

## 第3部 この「思考」に根拠がない部分（正直な限界）

`EVIDENCE_REGISTRY.md`は現時点で**空**である。テンプレート行しか入っていない。

つまり第1部で言語化した判断ロジックのうち、**一次情報源（BIS/FRB/査読論文/公式仕様等）に
裏付けられたものは1つもない**。以下はすべてHypothesis（`H`）またはUnclassified（`U`）である。

- EMA 20/75/200 という期間の選択
- 「3本が整列したら順張り」という判断
- ADX 20 という閾値
- 20EMA ±3 pips という接触帯
- 10 pips という逸脱上限
- 5本という遡り本数
- ATR×1.5 という損切り幅
- リスクリワード 1:2

これらは「よく使われている」以上の根拠を持たない。バックテストで成績が良かったことは
Evidenceへの昇格理由にならない（`RESEARCH_CHARTER.md`第19節）。

加えて、ADXについては**再構築検証に失敗している**（H1 OHLCから再現したADXが
`MinimumADX=20`を34%下回る乖離を示した）ため、オフライン分析では現在も除外扱いになっている。

## まとめ

**売買の思考**は明快で、一文で言える：
「3本のEMAが整列し、ADXが勢いを示し、20EMAへ浅く押してから戻った瞬間に、
残高0.5%だけ賭けて、ATR×1.5の損切りとその2倍の利確を置き、あとは触らない。」

**検証結果**も明快である：
そのロジックは3つのベースライン期間すべてでPF 0.74〜0.76と負けており、損失のほぼ全額は
売り方向から出ていた。改善候補を4件試し、1件（H006）は発見期間で強い効果を示したが、
2つの独立した期間で再現せず、いずれも採用に至っていない。

そして最も重要な発見は、**改善効果よりも期間差のほうが大きい**という事実である。
現在はこの問題に対処するため、10年分のデータ基盤とウォークフォワード評価の整備を進めている。

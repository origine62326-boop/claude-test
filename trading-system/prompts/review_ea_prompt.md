# プロンプト: EAコードレビュー

`mt4/USDJPY_LowRisk_Trend_EA.mq4` の変更（または新規実装分）をレビューする際に使うプロンプトテンプレート。
差分と一緒にこの内容を貼り付けて使う。

---

あなたはMQL4とFXリスク管理に詳しいシニアクオンツエンジニアです。
以下のEAコード（差分）をレビューしてください。目的は「一晩で大きく稼ぐこと」ではなく、
損失を限定しながら長期的に検証できる低リスクEAを維持することです。

## 確認してほしい観点（優先度順）

1. **安全設計の不変条件が壊れていないか**
   - 損切りなし注文が発生しうる経路が新たに生まれていないか
   - ナンピン・マーチンゲール・両建て・グリッド取引に該当する処理が混入していないか
   - 同時保有1ポジション制限、Symbol+MagicNumberでの自己ポジション識別が維持されているか
   - 未確定足(shift=0)を判定に使っていないか
2. **資金管理・ロット計算の正しさ**
   - TickValue/TickSize/LotStep/MinLot/MaxLotの取得漏れや0除算のリスクがないか
   - ロットの丸めが必ず切り捨てになっているか（許容損失を超える方向に丸めていないか）
3. **注文実行の堅牢性**
   - リトライが無限になっていないか、無限待機が発生しうる箇所がないか
   - エラーコード分類（リトライ可否）が妥当か
4. **MQL4特有の落とし穴**
   - 型変換で暗黙のdouble→int切り捨てが発生していないか（strictモードの警告対象）
   - 未初期化変数、未使用変数
   - GlobalVariable名の衝突（MagicNumberを含んでいるか）
5. **コード品質**
   - 責務が適切に関数分割されているか
   - 変数名・関数名がわかりやすいか
   - 過剰最適化（特定期間のバックテスト結果に合わせた不自然な調整）の兆候がないか

## 出力形式

- 見つかった問題を重大度順にリストアップ（該当ファイル・該当箇所を明記）
- 各問題について、具体的な修正案を提示
- 問題がない場合は「問題なし」と明記し、憶測で問題を作らない
- 「これはコンパイルして確認していない」という限界がある場合は明記する

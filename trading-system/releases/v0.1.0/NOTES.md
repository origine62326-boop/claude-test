# v0.1.0 リリースノート

## 概要

`USDJPY_LowRisk_Trend_EA`（MQL4 EA、Phase1-4実装）と、そのバックテスト結果を分析する
`trading-system/`（Pythonパイプライン）の初回統合バージョン。以降、このプロジェクトは
EA本体とバックテスト分析パイプラインをセットで、このバージョン番号で管理する。

## 含まれるもの

### EA (`mt4/USDJPY_LowRisk_Trend_EA.mq4`)

- Phase1: 入力パラメータ・OnInit検証・ログ基盤
- Phase2: トレンド判定(20/75/200EMA)・ADXフィルター・押し目/戻り判定（発注なし）
- Phase3: ATRベースSL/TP計算・リスク%からのロット自動計算（発注なし、検証ログ付き）
- Phase4: SafeOrderSend/Modify/Close（リトライ上限付き）・ECNフォールバック・
  実口座誤稼働防止(AllowLiveTrading)
- ユーザー環境のMetaEditorでコンパイル確認済み: 0 errors, 0 warnings
- Phase5(建値移動/トレーリング)・Phase6(日次損失上限/連敗制限)・Phase7(取引時間フィルター)・
  Phase8(スプレッド強化/FreezeLevel対応)は未実装

### 分析パイプライン (`analysis/`, `scripts/`, `tests/`)

- MT4レポート/操作履歴HTMLのパーサー、指標計算、安全設計違反の異常検知、
  年別/月別・買売別・時間帯別・時系列ブロック別分析、バージョン比較、Markdownサマリー生成
- pytest 19件、fixtureデータで全パス
- **実際のMT4出力ファイルでの検証はまだ未実施**（最優先のTODO）

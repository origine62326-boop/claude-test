# v0.2.0 リリースノート

## 概要

EA (`mt4/USDJPY_LowRisk_Trend_EA.mq4`) には一切変更なし。今回の目的は売買ロジックの
変更ではなく、バックテスト結果を保存・解析できる最小構成の分析パイプラインを
完成させることだった。

## 変更点

### `analysis/parse_mt4_report.py`（全面改訂）

- 抽出フィールドを要求仕様どおり20項目に整理: EA名・通貨ペア・時間足・
  テスト開始日/終了日・初期証拠金・通貨・モデリング品質・不整合チャートエラー・
  総取引回数・純利益・総利益・総損失・プロフィットファクター・期待値・
  最大ドローダウン額/率・勝率・最大連勝・最大連敗
- **日本語版・英語版どちらのMT4レポートにも対応**（ラベルごとに日英パターンを用意）
- バグ修正2件（v0.1.0時点の実装にあった問題）:
  1. 最大連勝/連敗セルで、金額と回数を取り違えていた
  2. 相対ドローダウンのフォールバック値で、主値/副値を取り違えていた
- 整数フィールド（取引回数等）が `192.0` のような小数表示にならないよう修正

### `analysis/performance_metrics.py`（機能追加）

- `validate_report_data()` を新設。レポートデータの欠損値・異常値・整合性
  （純利益 = 総利益+総損失、等）を検査する
- 既存のトレード明細ベースの指標再計算はフル版パイプライン向けとして維持

### `analysis/generate_summary.py`（機能追加）

- `render_minimal_summary()` を新設。バックテスト条件・純利益・PF・最大DD・
  勝率・取引回数・最大連敗・モデリング品質・注意点・次に確認すべきこと、を
  含む初心者向け日本語Markdownサマリーを生成する

### `scripts/run_analysis.py`（CLI再設計）

```
python scripts/run_analysis.py reports/raw/xxx.htm
```

の1コマンドで最小構成パイプラインが実行できるようになった。`--trades`を追加
指定すると、既存のフル版パイプライン(トレード明細分析)も引き続き実行できる。
入力ファイル(`reports/raw/`配下)を書き換えるコードパスが無いことを確認済み。
